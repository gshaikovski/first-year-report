\chapter{Extended Abstract}

The open problem addressed in this thesis is how autoregressive language models can learn to solve sequential pathfinding problems using structured and systematic search-augmented reasoning~(SA), with better compute and sample efficiency than current approaches.
Pathfinding  problems are characterised by an initial state, a goal state or a desired outcome, legal transition rules between states, and restrictions on these transitions.
Solving these problems involves creating step-by-step plans that reach the goal.
These criteria are very broad and can include everything from solving mazes and mathematical puzzles, to proving theorems and automating scientific work.
This thesis by no means attempts to solve all these tasks.
Instead, it aims to contribute a new insight into when and why SA reasoning in language models is beneficial for solving such tasks, and a new methodology for instantiating SA reasoning efficiently.

Search-augmented reasoning is a type of intermediate computation used to improve performance of language models on complex problems.
It is contrasted with implicit solution-only~(SO) reasoning where language models generate a solution directly after receiving a problem in its input.
In the context of pathfinding tasks, the latter implies that a model produces an optimal path from the initial state to the goal state directly after the problem specification.
This makes SO reasoning the most computationally efficient approach, for training and test-time generation, and it also requires only the solution data.
However, it also forces every decoded step of the solution to be correct, and sometimes, to produce even the first step correctly, the model must solve the entire problem \textit{a priori}.
This constraint can make it hard for the model to learn to solve the task, requiring exponentially more data and/or larger model.
With intermediate computation, a model can compute a solution in-sequence instead of in-depth, unrolling computation over theoretically unlimited number of token positions before decoding the first step of the solution.
Such intermediate reasoning traces can include additional deliberation about the problem, e.g., analysis of problem's structure, inferences about potential solutions, and trial and error attempts to solve the problem.
Many language-based complex tasks that involve pathfinding as part of the solution, such as planning or solving math problems, benefit from intermediate reasoning, so any improvement can result in more capable language models.
This framework can further be expanded to non-deterministic problems and environment interactions by re-framing an optimal path solution as the best guess of the future trajectory, with the language model acting as policy that combines action model with a world model of the environment.
However, these improvements must be evaluated against added cost of intermediate reasoning traces relative to SO reasoning, which includes significantly higher compute resources and additional reasoning data.

Reasoning in the intermediate tokens can be formalised as a form of search: the model explores potential solutions, evaluates its steps, and abandons unpromising directions.
If the process is bootstrapped from reasoning data that is neither structured nor systematic and conducted in human-like prose, a model may develop inefficient and unsound reasoning strategies that can hurt performance.
Systematic, sound, and efficient reasoning that imitates a search algorithm more closely may help to overcome these issues.
However, it suffers from a limitation: search trace data is usually not readily available for a given problem and must be generated, and if it can be generated then there already must exist a process that can use search to solve the problem.
A simple example is maze navigation: using procedure cloning to train a language model to search through a maze depends on availability of a symbolic solver that can search through the maze.
This thesis asks the following questions:

\begin{enumerate}[leftmargin=9pt, topsep=0pt]
    \item When is SA reasoning that follows a structured search process beneficial, compared to implicit SO reasoning, and when is it optional or even detrimental?
    \item How does problem structure and its representation influence relative performance and efficiency of SA and SO reasoning?
    \item Can we achieve performance of SA reasoning with other types of intermediate reasoning that do not require search traces?
    \item For the tasks where SA reasoning is the most optimal method to achieve high performance, how can the reasoning data for it be obtained if it does not yet exist?
\end{enumerate}
