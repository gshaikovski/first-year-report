\section{Motivation}
\label{sec:progress_motivation}

Section~\ref{sec:bg_search_lm_incontext} ends with an ambiguity in the literature.
SA-CoT outperforms SO learning when both are trained on the same fixed dataset~\citep{lehnertBetterPlanningTransformers2024,gandhiStreamSearchSoS2024}; yet with more data SO models can reach the performance of SA-CoT models~\citep{lehnertBetterPlanningTransformers2024}, SO models with test-time scaling can outperform SA-CoT models at test-time compute parity~\citep{qinBacktrackNotBacktrack2025}, and traces semantically unrelated to the problem can perform as well as genuine traces~\citep{valmeekamSemanticsUnreasonableEffectiveness2025}.
These results suggest that explicitly learning a search algorithm may be unnecessary or inefficient, but, as Section~\ref{sec:bg_gap_efficiency} argues, none of them provides conclusive evidence, since all fix the dataset size and none accounts for the training compute that a search trace adds.
The study therefore asks: \emph{how do the relative performance and the compute efficiency of SA-CoT and SO reasoning compare across search problems as the available data and model parameters increase?}

\section{Experimental design}
\label{sec:progress_setup}

% TODO: one figure with example SA-CoT and SO training sequences for both tasks.
We use two search problems with different structure, representation, and heuristics.
In maze navigation, the state graph is explicit: the grid is listed in the prompt and the edges are implicit pairs of adjacent cells; search traces are generated by A*, following~\citet{lehnertBetterPlanningTransformers2024}.
In Countdown, the graph is implicit: the prompt gives only a list of integers and a target, and every intermediate state must be computed by applying arithmetic operations; search traces are generated by depth-first search, following~\citet{gandhiStreamSearchSoS2024}.
We use both a regular Countdown game from~\citet{gandhiStreamSearchSoS2024} with varying problem complexity and a modular Countdown game, in which arithmetic is performed modulo a fixed integer, so that the transition structure of the problem can be changed while the encoding, the trace grammar, the model, and the training procedure stay fixed.
We train GPT-2 transformers~\citep{radfordLanguageModelsAre} of 4 to 12 layers from scratch on SA-CoT or SO data, training on increasing fractions of the full training dataset to account for effects of data scaling, with each run completing its own learning-rate schedule and run 5 times with different seeds.
Models are compared on held-out problems at matched training compute measured in FLOPs, and at matched test-time compute, where SO models may sample several candidates and select one with a symbolic verifier, following~\citet{qinBacktrackNotBacktrack2025}.

\section{Results}
\label{sec:progress_results}

\paragraph{Maze navigation is search-optional.}
% TODO: Figure: final_maze_vs_flops (solution error vs training FLOPs, SA-CoT vs SO, three depths).
SO models reach the same near-perfect accuracy as SA-CoT models with less total training compute, despite requiring marginally more data, and increasing model depth reduces the remaining sample-efficiency gap while preserving the compute advantage of SO models.
Search traces therefore have limited effect on accuracy but a substantial negative effect on training and test-time compute efficiency on this problem.

\paragraph{Countdown is search-efficient.}
% TODO: Figure: final_countdown_error and countdown_pass_at_k_flops.
Only SA-CoT models with optimal DFS traces learn the task efficiently.
On SoS Countdown, SO models generalise only after seeing 120x more data than SA-CoT models, which takes 5x more training FLOPs.
On modular Countdown, SO models with 6x more parameters fail to generalise in our experiments even after training on 200x more data and 140x more FLOPs than the most compute-efficient SA-CoT model.
At test-time compute parity, the best SO model with sampling and a verifier reaches 75\% accuracy against near-perfect accuracy for a single SA-CoT rollout, and the test-time scaling curves of the 59M- and 344M-parameter SO models overlap, so model size provides little benefit in this regime.
Compared to maze navigation, this result inverts the argument for search trace utility in its favour, which motivates out hypothesis that relative efficiency of SA-CoT depends on the problem structure.
This result feeds directly into the work that will address Gap~1, and will be further discussion in Section~\ref{sec:proposal_rq1}.

Another result in this experiment highlights how the trace itself affects learning efficiency.
The original SA-CoT traces from~\citet{gandhiStreamSearchSoS2024} were derived from suboptimal search strategies designed to fail $43\%$ of the time.
In our experiments, we find they underperform SO as sample size increases and saturate above the $5\%$ solution error threshold, hence never achieving ID generalisation.
This provides evidence that even in search-efficient regime, a suboptimal trace can limit learning.
The same traces were also used to compare SO and SA-CoT models on test-time compute parity by~\citet{qinBacktrackNotBacktrack2025}, which may be the reason why SO models outperformed SA-CoT models at test-time compute parity.
This result highlights the importance to consider the trace structure when analysing learning efficiency, contradicts some conclusions in prior work discussed in Section~\ref{sec:bg_gap_trace}, and will be considered later in Section~\ref{sec:proposal_rq2} where we investigate the ingredients that enable efficient learning with search traces.

\paragraph{Two learning regimes, determined by the problem.}
These observations are formalised in the following definition, which is the instrument used throughout Chapter~\ref{ch:proposal}.
\begin{tcolorbox}[title=Definition (Learning regimes), colback=ThesisGrey!5, colframe=ThesisGrey, fonttitle=\bfseries]
For a supervision mode $m \in \{\text{SA-CoT}, \text{SO}\}$ and a model size $N$, let $C_m(\epsilon; N)$ be the least training compute, and $D_m(\epsilon; N)$ the smallest number of training samples, with which a size-$N$ model trained under mode $m$ reaches held-out solution error $\epsilon$.
The learning problem is $\epsilon$-\emph{search-optional} if for every model size $N_\epsilon$ at which SA-CoT reaches error $\epsilon$ there is a model size $N$ with $C_\text{SO}(\epsilon; N) \le C_\text{SA-CoT}(\epsilon; N_\epsilon)$ and $D_\text{SO}(\epsilon; N) \le D_\text{SA-CoT}(\epsilon; N_\epsilon)$.
It is $\epsilon$-\emph{search-efficient} if there is a model size $N_\epsilon$ such that every model size $N$ satisfies $C_\text{SO}(\epsilon; N) > C_\text{SA-CoT}(\epsilon; N_\epsilon)$ and $D_\text{SO}(\epsilon; N) > D_\text{SA-CoT}(\epsilon; N_\epsilon)$.
\end{tcolorbox}
Maze navigation is search-optional; Countdown is search-efficient.
We hypothesise that, since varying depth and width does not change the regime while changing the problem, the regime is determined by the problem's structure rather than by dataset or model size.
Crucially, SA-CoT models outperform SO models at small dataset sizes in both regimes, so a comparison at a single dataset size cannot identify the regime; this is why the prior comparisons described in Section~\ref{sec:bg_search_lm_incontext} disagree.

\paragraph{The effect of trace semantics depends on the regime.}
% TODO: Figure: final_trace_types_8l.
Replacing each search trace with a trace from an unrelated problem, following~\citet{valmeekamSemanticsUnreasonableEffectiveness2025} gives models that perform worse than both SA-CoT and SO models on search-optional maze navigation, but better than SO models in sample efficiency on search-efficient modular Countdown, reaching 81\% accuracy with 20M samples while still falling short of SA-CoT models.
Trace semantics therefore matter in both regimes, contrary to the prior conclusion, and the sample-efficiency advantage of unrelated traces in the search-efficient regime, which increasing model size alone does not produce, is left unexplained.
This result informs my approach when I describe a proposal to address Gap~2 in Section~\ref{sec:proposal_rq2}.

\paragraph{Knowing the regime yields a more compute-efficient data mixture.}
% TODO: Figure: final_mixture_error.
Training one model on both tasks with the reasoning approach chosen per task based on its regime, SO for maze navigation and SA-CoT for modular Countdown, reaches generalisation on both tasks with less training compute than training with SA-CoT or with SO data on both.

\section{Additional pilot experiments}
\label{sec:progress_pilots}

% NOTE: unpublished pilots; state seeds/settings if any are reported as numbers.
Three further experiments, not included in the paper, inform the research questions of Chapter~\ref{ch:proposal}.
First, pause and filler tokens~\citep{goyalPauseTokens2024,pfauLetsThinkDot2024} appended to SO data are trivially learnable by the model and produce no effect on either task, so the learning problem collapses into SO learning.
Second, models trained with corrupted or unrelated traces on maze navigation learn to ignore the traces once they generalise in-distribution, which likewise collapses to SO learning; only on modular Countdown do unrelated traces retain an effect, as reported above.
Third, the best SA-CoT model trained on modular Countdown with three numbers, tested on puzzles with four and five numbers, shows a severe drop in performance; the current trace format and setup therefore do not generalise in length, and this result serves as the control baseline for Section~\ref{sec:proposal_rq3} which addresses Gap~3.

\section{Outlook}
\label{sec:progress_outlook}

The study argues that there are search problems on which SA-CoT learning is the most sample- and compute-efficient method for in-distribution generalisation, that this is not the case for every search problem, and that which case applies is decided by the problem's structure rather than by scale.
It defines two learning regimes for search problems that separate the problems by the relative sample and compute efficiency of SA-CoT compared to SO learning.
It also demonstrates that suboptimal or unrelated traces hinder performance and learning efficiency of SA-CoT, which may fall behind SO learning even on problems where optimal SA-CoT is more efficient.
Finally, it provides the protocol, specifically, matched-compute comparison across data and model sweeps in both regimes, which establishes the regime for a given problem.
For Research Question~1, it leaves open which properties of the structure determine the regime: the evidence rests on two problems and one intervention, and the candidate factors are not isolated; it also leaves open whether other regimes are possible in practice, since the provided definition does not exhaustively define all possible regimes.
For Research Question~2, it leaves open what the trace supplies in the search-efficient regime, why suboptimal traces perform worse, and why unrelated traces retain part of the benefit and outperform SO data.
For Research Question~3, it shows only that the current setup does not generalise in length, and everything beyond in-distribution generalisation remains to be done.
Chapter~\ref{ch:proposal} takes up each of these in turn.
