% The field of artificial intelligence is split along two paradigms that developed largely in parallel.
% The first, and the oldest one, is the symbolic paradigm: algorithms are hand-designed to solve a specific problem that, for humans, is associated with intelligent problem-solving.
% An example is a computer program that plays chess by searching for the best move using user-defined heuristics.
% The other is the connectionist paradigm: an algorithm is a large function called a `neural network' composed of primitive functions with non-linearities and free parameters called `weighs'.
% The function is hand-designed but not adapted to any particular problem; instead, it `learns' how to solve problems by taking problem examples as input, computing solutions as output, and adjusting weights using gradient descent on the error between its output and the ground truth solutions.
